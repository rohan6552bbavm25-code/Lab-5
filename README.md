This project focuses on **iterative prompting**, which means improving an AI-generated response step by step through targeted follow-up prompts. The main objective is to understand that the first AI output should not be accepted automatically and must be reviewed, diagnosed and improved before use in aviation communication.

The activity uses an aviation scenario involving **Flight AV307 from Chandigarh to Mumbai**, which is delayed by 75 minutes due to adverse weather, with a revised departure time of 7:15 PM. Students first generate a passenger announcement using a simple prompt and then check it for factual accuracy, missing information, unsupported claims, tone, length and passenger instructions.

The project follows an **Iteration Relay** process: Generate → Evaluate → Diagnose → Repair → Review → Approve. Students improve the announcement one problem at a time by using follow-up prompts. These improvements include correcting flight details, removing unsupported gate numbers or compensation promises, adding passenger instructions, improving the tone, controlling the word limit and adding a verification safeguard such as `[VERIFY WITH OFFICIAL SYSTEM]`.

A second activity focuses on a baggage complaint response where the AI makes unsupported promises about delivery time, compensation and upgrades. Students identify these risks and use targeted prompts to create a more professional and non-committal response.

The lab also includes creating an original aviation iteration relay, peer review, reflection questions and maintaining a complete prompt-refinement trail. Finally, the completed activity is saved as `iteration-relay.md` and uploaded to the `genai-business-portfolio` GitHub repository.

Overall, this project demonstrates how targeted follow-up prompts can make AI outputs more accurate, clear, safe and suitable for human review in aviation.
